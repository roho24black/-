# 🌳 Семейное древо

Однофайловое веб-приложение для построения семейного древа. Не требует
установки, сборки и интернета — просто откройте `index.html` в браузере
(отлично работает и на телефоне, все данные хранятся локально на
устройстве).

## Что умеет

- 👤 **Карточка человека**: имя, фамилия, девичья фамилия, пол, дата и
  место рождения, дата и место смерти, заметки. Даты можно указывать
  неточно — «около 1930» или просто год.
- 🌿 **Ветвистое дерево**: у каждого человека из его карточки можно одним
  нажатием добавить отца, мать, супруга/супругу, ребёнка, **брата или
  сестру**, а также **дядю или тётю** — приложение само подставит нужных
  общих родителей (а если их ещё нет в дереве, автоматически создаст
  «родителя-заглушку», которого можно будет дозаполнить позже). Так дерево
  сразу разрастается вширь, а не только вверх-вниз.
- 🔀 Поддерживаются повторные браки, сводные братья/сёстры и связывание
  уже существующих в дереве людей (а не только создание новых).
- 🚫 Защита от «замкнутых» связей — нельзя случайно назначить человека
  своим же потомком.
- 🔍 Поиск по имени, фамилии и месту рождения с подсветкой на дереве.
- 🔎 Масштабирование и прокрутка дерева, отдельный список всех людей.
- 💾 Данные сохраняются в браузере (localStorage). Кнопки **«Экспорт»** и
  **«Импорт»** позволяют скачать/загрузить резервную копию в JSON —
  удобно для переноса между устройствами.
- 🖨 Печать / сохранение в PDF прямо из браузера.
- 📱 Полностью адаптивно под телефон — можно вводить данные прямо в
  пути.

## Как запустить

Просто откройте `index.html` в любом современном браузере (двойной клик,
или перетащить в окно браузера). Работает полностью локально, интернет не
нужен.

## Модель данных

Всё родство строится всего на двух вещах у каждого человека: **отец** и
**мать** (ссылки на других людей в дереве) плюс список **супругов**.
Братья/сёстры — это просто люди с одинаковыми родителями, а дяди/тёти —
братья/сёстры одного из родителей. Быстрые кнопки «+ Брат/сестра» и
«+ Дядя/тётя» на карточке человека сами расставляют эти связи правильно.
