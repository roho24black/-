# Что? Где? Когда? — пульт ведущего

Однофайловое веб-приложение для ведущего домашней игры «Что? Где? Когда?».
Не требует установки и сборки — просто откройте `index.html` в браузере
(на телефоне ведущего это тоже отлично работает), либо откройте живую
версию на GitHub Pages и поставьте её на домашний экран как приложение.

## Что умеет

- 🎡 Волчок с 13 секторами: сектора не подписаны цифрами (кроме 13-го) —
  нетронутые показывают конверт ✉, а уже сыгранные превращаются в стрелку →,
  так что по волчку видно прогресс игры. Вращение по-настоящему случайное.
- 🌐 **Сектор 13** — всегда вопрос «из интернета» (обычный, идёт в общий
  счёт), как в реальном эфире.
- ⚡🏆 **Блиц и Суперблиц** — ещё два сектора (заранее неизвестно, какие
  именно из 1–12), по официальному регламенту (chgk.tvigra.ru/reglament):
  3 вопроса, 20 секунд на каждый, нужны все три верных подряд — одна ошибка
  проваливает весь сектор. В «Блице» отвечает вся команда, в «Суперблице» —
  один игрок по решению капитана (выбирается из состава команды).
- 👥 **Состав команды и капитан** — задаются на экране настройки, капитан
  виден в шапке игры, а при суперблице его можно быстро выбрать игроком за
  столом (или вписать другое имя).
- ⏱ Таймер обсуждения (по умолчанию 60 сек) с кольцом-прогрессом и
  звуковыми сигналами (синтезированы прямо в браузере, без аудиофайлов).
- 🎓 Классические фишки ЧГК: **досрочный ответ** (даёт знатокам
  дополнительную минуту на точную формулировку) и **минута в кредит**
  (продлевает текущий раунд на 60 сек, снимая 30 сек с одного из будущих
  вопросов этой же игры).
- 🏆 Счёт «Знатоки» против «Телезрителей» до 6 очков.
- 🏙 Город и отправитель вопроса — как в телевизионной подаче.
- 📚 Большая база реальных вопросов из открытой базы «Что? Где? Когда?»
  (db.chgk.info), с атрибуцией автора и турнира под каждым ответом.
- 🔁 «Собрать игру» каждый раз берёт новые 13 вопросов без повторов — пока
  не исчерпается вся база (тогда начинается новый круг).
- 📱 Ставится на домашний экран как настоящее приложение (PWA: манифест,
  иконка, кнопка установки на Android, подсказка для iPhone/Safari).
  Полностью адаптивно, крупные кнопки, работает офлайн после первой загрузки.

## Как запустить

Просто откройте `index.html` в любом современном браузере, либо откройте
живую версию, опубликованную на GitHub Pages. Работает полностью локально,
интернет нужен только один раз — чтобы открыть страницу.

## Как обновить базу вопросов

Все вопросы лежат в файле `index.html` в массиве `const QUESTIONS = [...]`
(в начале `<script>`). Каждый вопрос — объект с полями `id`, `question`,
`answer`, `acceptable`, `comment`, `source`, `author`, `tournament`,
`difficulty`. При сборке игры 10 вопросов уходят на обычные сектора, 1 — на
сектор 13 (интернет), по 3 — на блиц и суперблиц.

## Источник вопросов

Вопросы взяты из открытой базы вопросов «Что? Где? Когда?»
([db.chgk.info](https://db.chgk.info)) — она специально создана и
поддерживается сообществом для свободного использования клубами и семьями
при проведении собственных игр. Под каждым ответом в приложении показана
атрибуция (автор и турнир). Небольшая часть вопросов написана специально
для этого приложения (изначально задумывались как вопросы 13-го сектора,
теперь просто часть общей базы, помечены полем `original: true`).

Правила «Блиц» и «Суперблиц» — по официальному регламенту телекомпании
«ИГРА-ТВ»: [chgk.tvigra.ru/reglament](https://chgk.tvigra.ru/reglament/).
